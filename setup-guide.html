🚀 Deployment Workflow

1. Push to main branch
↓
2. GitHub Actions triggered
↓
3. Deploy to GitHub Pages
↓
4. Plugin live at GitHub.io

⚙️ Setup Steps

1

Merge This PR

Merge this pull request to the main branch to add the deployment workflow and plugin manifest.

2

Enable GitHub Pages

Go to Repository Settings → Pages, and under Source, select GitHub Actions.

3

Wait for Deployment

The workflow will automatically deploy the plugin. Check the Actions tab to monitor progress.

4

Plugin is Live!

Once deployed, the plugin will be accessible at:

https://mottet.github.io/standardnotes-reminder-plugin/plugin.json

📱 Install in StandardNotes

💡 Quick Install: Users can install the plugin by pasting the URL below in StandardNotes Extensions.
1

Open StandardNotes

Open StandardNotes and navigate to Extensions (or Account → Extensions).

2

Import Extension

Scroll to Import Extension and paste this URL:

https://mottet.github.io/standardnotes-reminder-plugin/plugin.json
3

Click Install

Click the Install button and the reminder plugin will be added to your StandardNotes!

🎯 Plugin Features

  • ✅ Add reminders with specific date and time
  • ✅ Optional notes for each reminder
  • ✅ Visual indicators (overdue/due soon/scheduled)
  • ✅ Browser notifications when reminders are due
  • ✅ Automatic deployment via GitHub Actions
  • ✅ Easy one-click installation in StandardNotes
